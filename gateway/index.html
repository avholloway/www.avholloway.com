            Template assumes a single interface; hence no bind commands. If you
            want multiple interfaces, you may need to consider your binds.
          
    • 
          
  • 
            I prefer to decouple the WxC subnets in the trust list. If you
            prefer to define them, please do so.  WxC IP Subnets
          
    • 
          
  • 
            I also then decouple the CUCM addresses in the trust list too, as any server you send to, is auto trusted.  However, if you send to less CUCM nodes than you receive from (i.e., You use run on all nodes), then you will have to add those CUCM nodes to the trust list.
          
    • 
          
  • 
            My numbering convention for dial-peers and other items is as follows:
            
      
              
    • 
                It's a four digit number pattern: XYZZ
                
        
                  
      • Where the first digit "X" is the leg or side; 1 = Webex, 2 = CUCM
        • 
                  
      • 
                    The second digit "Y" is the direction; 1 =
                    Incoming, 2 = Outgoing, 0 = Bidirectional
                  
        • 
                  
      • 
                    The next two digits "ZZ" are not used in my template so they're always "00", but could be used if you added more dial peers.  Say for example, you switched from DPGs to destination patterns, then the local DP could be "01", and long distance "02", etc.
                  
        • 
                
      
              
      • 
            
    
          
    • 
          
  • 
            Speaking of destination patterns, mine is "ABC123" because we need the destination-pattern command, but the value is ignored.  Instead of putting in a realistic looking value, which may confuse people (e.g., 9.[2-9]..[2-9]......), I use a slightly more silly pattern, to hopefully re-enforce the idea that it's not used.  The official guide uses "BAD.BAD" but I don't like how that looks, so I use "ABC123" instead.
          
    • 
          
  • 
            This template is designed for two CUCM servers, but feel free to
            adapt it for more servers or for another PBX (e.g., Avaya).  Just generate the template with your two server addresses, then after you copy the config to your text editor, manually add the additional entries.  Please note, server-groups, as of this writing, only support up to 5 servers in them.
